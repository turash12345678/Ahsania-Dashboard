# ⚡ Visual Canvas Cheat Sheet

## 1. Start Here
- **File:** `design-system/ahsania-ui.pen`
- **Action:** Double-click to open. Etai apnar "Design Board".

## 2. Kaje Lagbe
- **Canvas:** Ekhane Visual Change korben.
- **Code:** Canvas e change korle Code auto update hobe.

## 3. Save Kora
- **Command:** `npm run design:save`

## 4. Problem?
- Jodi `.pen` file open na hoy, bam pasher menu theke "Pencil" icon e click kore file ta open korun.
