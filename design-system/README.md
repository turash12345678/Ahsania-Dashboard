# Ahsania Dashboard Design System

Welcome to the Design System for the Ahsania Dashboard. this folder acts as the single source of truth for all UI/UX related decisions, assets, and workflows.

## 📂 Folder Structure

- **[ahsania-ui.pen](./ahsania-ui.pen)**: 🎨 **START HERE!** This is your Visual Canvas. Open this file to visually design your app.
- **[STYLE_GUIDE.md](./STYLE_GUIDE.md)**: Color palettes, typography, spacing, and other core design tokens.
- **[COMPONENTS.md](./COMPONENTS.md)**: A catalog of all reusable components.
- **[WORKFLOW.md](./WORKFLOW.md)**: Instructions on how to use Pencil.dev -> Git -> Deploy.

## 🎨 Philosophy

1.  **Visual First**: We use **Pencil.dev** as our primary tool for visual editing. Changes made visually should be reflected in code.
2.  **Utility First**: We leverage **Tailwind CSS** for styling, ensuring consistency and rapid development.
3.  **Component Driven**: We build small, reusable components (following Atomic Design principles) to complex interfaces.
